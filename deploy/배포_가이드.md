# 코스톨라니 달걀 대시보드 — 배포 가이드

폰·PC 어디서나 브라우저 URL로 열고, 홈 화면에 **앱처럼 설치**할 수 있는 배포 방법입니다.
빌드(컴파일)가 필요 없습니다. `deploy` 폴더의 4개 파일만 그대로 올리면 됩니다.

## 📁 배포할 파일 (deploy 폴더)

| 파일 | 역할 |
|---|---|
| `index.html` | 대시보드 본체 (React·Recharts를 CDN으로 불러오는 단일 파일) |
| `manifest.webmanifest` | PWA 앱 정보 (이름·아이콘·전체화면) |
| `sw.js` | 서비스워커 (앱 셸 캐시) |
| `icon.svg` | 앱 아이콘 |

> 이 4개 파일은 **같은 폴더에 함께** 있어야 합니다.

---

## 방법 A. Netlify Drop — 가장 빠름 (계정 가입 없이 1분)

1. 브라우저에서 **https://app.netlify.com/drop** 접속
2. `deploy` 폴더를 통째로 페이지 위로 **드래그 앤 드롭**
3. 몇 초 뒤 `https://random-name.netlify.app` 주소가 생성됨 → 폰에서도 이 주소로 접속
4. (선택) 무료 가입하면 주소 이름 변경·재배포 관리 가능

가장 손쉽게 "지금 당장" 폰에서 확인하고 싶을 때 추천.

---

## 방법 B. Vercel — 자동 재배포까지 (추천, 무료)

깃허브에 올려두면 파일이 바뀔 때마다 자동으로 다시 배포됩니다. (예약작업이 `index.html`을 갱신 → push → 자동 반영)

1. https://github.com 에서 새 저장소(repository) 생성
2. `deploy` 폴더 안 4개 파일을 저장소에 업로드 (웹 UI의 *Add file → Upload files* 로도 가능)
3. https://vercel.com 가입 → **Add New → Project** → 방금 만든 깃허브 저장소 선택
4. 프레임워크는 **Other**, 빌드 설정은 비워둔 채 **Deploy**
5. `https://프로젝트명.vercel.app` 주소 생성 완료

이후 저장소 파일을 수정(또는 push)하면 Vercel이 자동 재배포합니다.

---

## 방법 C. GitHub Pages — 깃허브만으로

1. 저장소에 4개 파일 업로드
2. 저장소 **Settings → Pages → Source: Deploy from a branch → main / (root)** 저장
3. 1~2분 뒤 `https://아이디.github.io/저장소명/` 주소 생성

---

## 📱 폰 홈 화면에 앱처럼 설치 (PWA)

위 방법 중 하나로 배포해 **https:// 주소**가 생긴 뒤:

- **아이폰(Safari):** 주소 접속 → 공유 버튼 → **홈 화면에 추가**
- **안드로이드(Chrome):** 주소 접속 → 우측 상단 ⋮ → **앱 설치 / 홈 화면에 추가**

설치하면 주소창 없는 전체화면 아이콘 앱으로 실행됩니다.
서비스워커는 **https 또는 localhost에서만** 동작하므로, 파일을 그냥 더블클릭(file://)해서 열면 PWA 설치는 안 되고 화면 보기만 됩니다.

---

## 🔄 데이터 갱신은 어떻게?

이미 **예약작업(`kostolany-dashboard-refresh`)**이 평일 아침 최신 금리·지수를 조회해
`KostolanyEggDashboard.jsx`와 `deploy/index.html`의 앵커값을 자동 갱신하도록 설정돼 있습니다.

- **방법 B(Vercel + 깃허브)**를 쓰면: 예약작업이 값 갱신 → 깃허브에 push만 하면 자동 재배포 → 폰에서 새로고침 시 최신 반영.
- **방법 A/C**를 쓰면: 값이 갱신된 `index.html`을 다시 업로드(드롭)하면 반영됩니다.

> 참고: 이 대시보드는 예약작업이 채워 넣는 **일 단위 실측 앵커**로 구동됩니다.
> 장중 초 단위 실시간 시세가 필요하면 별도의 유료 지수 API 연동(라이브 버전)이 필요합니다.

---

## ⚠️ 주의

- 인터넷 연결이 필요합니다 (React·Recharts·Tailwind를 CDN에서 불러옴).
- 표시되는 지표는 시뮬레이션 앵커이며 **투자 조언이 아닙니다.**
- 아이폰 홈 아이콘을 완벽한 PNG로 쓰고 싶다면 `icon.svg`를 512×512 PNG로 변환해 `apple-touch-icon`으로 교체하면 됩니다(선택).
